## Reflection Desktop Highlights

- **Terminal Session:** Reflection Desktop terminal session opens a live screen on a host you are allowed to use, and it keeps that screen in a window you can return to.
- **3270 Screen:** Reflection Desktop 3270 shows the familiar mainframe layout for menus, fields, and function keys used in class or in a small operations office.
- **Host Profile:** Reflection Desktop host profile stores the address, the port, and the session name so the next sign-in does not start from a blank page.
- **Keyboard Map:** Reflection Desktop keyboard map places host keys where your hands already expect them, which matters during a long data-entry hour.
- **File Transfer:** Reflection Desktop file transfer moves a file you are allowed to exchange with that host, such as a class dataset or a small office extract.

## What Is Reflection Desktop

Reflection Desktop is a host-session helper for people who work on a mainframe screen as part of study or a small office routine. Reflection Desktop terminal session is the window. Reflection Desktop 3270 is the screen type many courses and business systems still use. You connect to a host you are permitted to use, sign in with the account you were given, and work in the fields on that screen.

Reflection Desktop host profile remembers how that connection is built, so a lab machine and a home study computer can open the same named session. Reflection Desktop keyboard map keeps Pf keys and other host keys consistent. Reflection Desktop file transfer is there when the task includes moving a file to or from the host, not as a separate puzzle. A student can practice a menu path, and a clerk can repeat a daily inquiry, with the same three supports behind the screen.

The helper stays on the session. Reflection Desktop terminal session, Reflection Desktop 3270, and Reflection Desktop host profile are the parts you touch every day. Reflection Desktop keyboard map and Reflection Desktop file transfer are the parts you adjust when the keys feel wrong or a file has to move. That is a complete small-office and classroom set for host work.

## Starting with Reflection Desktop

Prerequisites: A compatible computer, a host account you are allowed to use, and permission to run Reflection Desktop.

1. **Prepare:** Ask for the host address and the account before you open Reflection Desktop terminal session.
2. **Save The Profile:** Create Reflection Desktop host profile with that address and a clear session name.
3. **Open 3270:** Start Reflection Desktop 3270 and sign in with the account you were given.
4. **Fix The Keys:** Adjust Reflection Desktop keyboard map if a function key is not where the course notes say.
5. **Move One File:** Try Reflection Desktop file transfer with a small sample you are allowed to copy.
6. **Reuse The Name:** Next time, open the same Reflection Desktop host profile instead of building a new one.
